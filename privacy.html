This policy explains how Morning Aesthetics Uploader (“the app”) handles information. The app is a private tool used only by the owner of the Morning Aesthetics YouTube channel to upload that channel's own videos.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Information the app accesses

  • An OAuth 2.0 access/refresh token for the channel owner's Google account, with the single scope https://www.googleapis.com/auth/youtube.upload.
  • The video files, titles, descriptions and tags that the channel owner creates and chooses to upload.

The app does not read, collect or store any data about viewers, subscribers, comments, other channels, or any other YouTube users. It does not use cookies, analytics, or advertising.

How information is used

The token is used only to upload videos to the channel owner's own YouTube channel. Nothing else.

Storage and sharing

  • The token is stored only on the channel owner's own computer, in a local file. It is never sent to any server other than Google's.
  • No information is sold, shared with, or disclosed to any third party.
  • Video files are deleted from the computer after a successful upload.

Revoking access and deleting data

Access can be revoked at any time from the Google security settings page: security.google.com/settings/security/permissions. Deleting the local token file removes all stored authorization data. Uploaded videos can be managed or deleted in YouTube Studio.
